# Danny Capture (대니 캡처)

Windows 10/11 전용 강력하고 직관적인 화면 캡처 프로그램입니다.

## 설치 방법 (일반 사용자)

Python 등 별도 설치가 전혀 필요 없습니다.

1. 이 저장소의 **[Releases](../../releases) 페이지**에서 최신 `DannyCapture_Setup.exe` 를 내려받습니다.
2. 실행하면 사용자 폴더(`%LOCALAPPDATA%\DannyCapture`)에 설치되며 관리자 권한이 필요 없습니다.
3. 설치 후 트레이(작업표시줄 오른쪽 아래)에 아이콘이 상주합니다. `Ctrl+Shift+E` 로 바로 캡처를 시작하세요.

> ⚠️ 소스 코드를 zip 으로 받아 푸는 방식은 실행 파일이 아니므로 동작하지 않습니다.
> 소스로 실행하려면 아래 [개발자용] 절차를 따르세요.

## 주요 기능

1. **다양한 캡처 모드**
   - **간편 캡쳐** (Ctrl+Shift+E): 원하는 영역을 드래그하여 캡처
   - **전체화면 캡쳐** (Ctrl+Alt+F): 모니터 전체를 캡처
   - **창 캡쳐** (Ctrl+Alt+W): 특정 윈도우를 선택하여 캡처
   - **단위영역 캡쳐** (Ctrl+Alt+U): 영역을 지정하여 캡처
   - **크기지정 캡쳐** (Ctrl+Alt+S): 정확한 픽셀(W x H)을 입력하여 캡처
   - **마지막 영역 재캡처** (Ctrl+Alt+R): 직전 영역을 오버레이 없이 즉시 다시 캡처

2. **화면 동결 캡처**
   - 캡처를 시작하는 순간 화면이 그대로 얼어붙어, 드롭다운 메뉴·툴팁처럼
     클릭하면 사라지는 화면도 보이는 그대로 선택하고 캡처할 수 있습니다.
   - 화면에 보이는 것 = 돋보기에 보이는 것 = 저장되는 것 (픽셀 단위 일치)

3. **편리한 편집 기능 (어노테이션)**
   - 캡처 후 즉시 편집창: ✂ 자르기 · 펜 · 형광펜 · 사각형 · 화살표 · 텍스트
   - 색상 선택 시 색상표를 클릭하면 즉시 반영되고 창이 자동으로 닫힙니다.
   - 저장 시 자동 저장된 파일을 덮어써 파일이 이중으로 생기지 않습니다.

4. **백그라운드 동작**
   - 실행 시 시스템 트레이에만 상주하며 화면을 가리지 않습니다.
   - 중복 실행 방지: 두 번 실행하면 안내 후 종료됩니다.
   - 다른 프로그램이 단축키를 선점한 경우 시작 시 알려줍니다.

5. **자동화 및 연동**
   - 캡처 시 클립보드에 자동 복사, 파일 자동 저장(환경설정에서 끌 수 있음)
   - 기본 저장 경로: `내 PC > 사진(Pictures) > DannyCapture` (환경설정에서 변경)
   - Windows 알림(Toast) 제공

## 단축키·환경설정

- 트레이 아이콘 우클릭 → [환경설정]
- 단축키, 저장 폴더, 자동 저장/클립보드 복사, 이미지 포맷, 부팅 시 자동 실행을 변경할 수 있습니다.

## 빌드 방법 (개발자용)

1. Python 3.11+ 설치
2. 패키지 설치: `pip install -r requirements.txt`
3. 소스 실행: `python main.py`
4. 단일 exe 빌드: `python -m PyInstaller --clean DannyCapture_Single.spec` → `dist/DannyCapture_Single.exe`
5. 설치본 패키징(Inno Setup 6 필요): `ISCC.exe installer.iss` → `Output/DannyCapture_Setup.exe`

## 변경 이력

### v1.2.0 (2026-08-24)
- **화면 동결 캡처**: 캡처 시작 순간 화면을 동결해 드롭다운·툴팁 등 순간 팝업을 보이는 그대로 캡처. 오버레이·돋보기·결과물이 픽셀 단위로 일치.
- **✂ 자르기 도구**: 편집기에서 점선 드래그로 즉시 크롭.
- **마지막 영역 재캡처** (Ctrl+Alt+R): 트레이 메뉴·단축키로 직전 영역 즉시 재캡처. 모니터 구성이 바뀌어 영역이 화면 밖이면 안내.
- **저장 흐름 개선**: 자동 저장 on/off 설정 동작, 편집기 저장이 원본 파일을 덮어써 이중 파일 제거, 저장 실패 시에도 캡처를 잃지 않음.
- **중복 실행 방지** + 단축키 등록 실패/중복/오타 감지 및 알림.
- **저장 경로 이식성**: 기본 저장 경로가 사용자 사진 폴더로 — 어느 PC 에서도 동작.
- 기본 펜 색상 빨강, 색상 선택 창 자동 닫힘, 설정 변경 시 트레이 메뉴 즉시 갱신.

### v1.1.1 (2026-05-29)
- **최상단 가림 버그 완전 수정**: 윈도우 OS에서 부모가 없는 `Qt.Tool` 창이 항상 위에 머물러 다른 인터페이스를 가리는 현상을, 보이지 않는 가상의 더미 부모 윈도우를 지정하여 자연스럽게 다른 창 뒤로 가려지도록 개선(작업 표시줄 비노출 장점 유지).
- **시작 프로그램 자동 등록**: 컴퓨터 부팅 시 백그라운드로 자동 실행되도록 Windows 레지스트리 연동 구현.
- **환경설정 UI 통합**: 환경설정 창 내에 'Windows 시작 시 자동 실행' 옵션을 제공하여 실시간으로 부팅 설정을 제어할 수 있도록 보강.

### v1.1.0 (2026-05-28)
- **백그라운드 전용 모드**: 시작 시 툴바를 표시하지 않고 트레이에만 상주. 캡처 후 편집기만 표시되며, 편집기를 닫으면 자동으로 백그라운드 복귀.
- **최상위 고정 해제**: 툴바가 다른 창 위에 항상 떠 있지 않도록 변경.
- **기본 단축키 변경**: 간편 캡쳐 단축키를 `Ctrl+Alt+D` → `Ctrl+Shift+E`로 변경.
- **색상 즉시 적용**: 편집기 색상 선택 시 OK/Cancel 버튼 없이, 색상 클릭 즉시 펜·사각형·화살표에 반영.
